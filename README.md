# 🎭 빅데이터 분석을 통한 뮤지컬 지방 투어 공연 분석
> **Musical Tour Analysis through Big Data & Deep Learning**

대극장 뮤지컬의 지방 투어 확대에 따른 서울 공연과의 관람 경험 차이를 빅데이터 분석을 통해 탐색하고 분석하는 프로젝트입니다.

## 📝 프로젝트 개요
최근 몇 년간 대극장 뮤지컬의 지방 투어가 활발해졌지만, 지방 관객들이 서울 공연과 동일한 경험을 하는지에 대한 의문이 지속적으로 제기되고 있습니다. 본 프로젝트는 이러한 격차를 데이터로 증명하고 분석하는 것을 목표로 합니다.

## 🛠 주요 기술 및 도구
* **Language:** Python
* **Analysis:** Jupyter Notebook
* **Deep Learning:** BERT (Natural Language Processing for Sentiment Analysis)
* **Data:** 공연 관람 리뷰 및 소셜 데이터

## 📂 파일 구성
* `Untitled1.ipynb` : 작품 선정에 사용된 코드
* `성공 코드.txt`: NOL티켓에서 관람후기를 불러오는 코드(코랩에선 안됨)
* `딥러닝_언어_분류_with BERT.ipynb`: BERT 모델을 활용한 딥러닝
* `Untitled11.ipynb`: 학습된 모델을 바탕으로 관람후기 부정비율 검출
* `빅데이터와 분석_프로젝트.hwpx`: 상세 분석 결과 보고서

## 🔎 분석 결과
* 서울과 지방공연의 평점은 비슷하다.
* 부정 관람 후기의 경우 13%정도로 나타남
* 오케스트라의 경우 1 공연을 제외하고 오지 않았다.
* 캐스팅보드는 지방 투어 공연 66번 중 32번(48.5%)이 종이 안내판, 화면 제시 또는 미제공 형태로 나타났으며, 주연 중심 및 축소된 형식은 27번(40.9%)을 차지했다. 이에 따라 전체 출연진 정보가 포함된 형식은 7번(10.6%)으로 소수에 그치는 것으로 확인되었다.
* 포토존의 경우 포스터가 그려진 패브릭 인쇄물(81.8%), 포스터나 주연 사진이 그려진 캔버스 스탠딩 패널(15.2%), 서울 공연과 같이 입체 조형 포토존이 설치된 경우는 2번뿐이다.
* MD의 경우, 서울과 동일한 구성으로 지방 투어 공연에서 판매한 경우가 없다.
