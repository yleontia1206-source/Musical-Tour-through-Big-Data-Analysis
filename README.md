# 🎭 빅데이터 분석을 통한 뮤지컬 지방 투어 공연 분석
> **Musical Tour Analysis through Big Data & Deep Learning**

대극장 뮤지컬의 지방 투어 확대에 따른 서울 공연과의 관람 경험 차이를 빅데이터 분석을 통해 탐색하고 분석하는 프로젝트입니다.

## 📝 프로젝트 개요
최근 몇 년간 대극장 뮤지컬의 지방 투어가 활발해졌지만, 지방 관객들이 서울 공연과 동일한 경험을 하는지에 대한 의문이 지속적으로 제기되고 있습니다. 본 프로젝트는 이러한 격차를 데이터로 증명하고 분석하는 것을 목표로 합니다.

## 🛠 주요 기술 및 도구
* **Language:** Python
* **Analysis:** Jupyter Notebook
* **Deep Learning:** BERT (Natural Language Processing for Sentiment Analysis)
* **Data:** 공연 관람 리뷰 및 소셜 데이터 (추정)

## 📂 파일 구성
* `Untitled1.ipynb`, `Untitled11.ipynb`: 데이터 전처리 및 분석 과정
* `딥러닝_언어_분류_with BERT.ipynb`: BERT 모델을 활용한 관람평 감성 분류 및 분석
* `빅데이터와 분석_프로젝트.hwpx`: 상세 분석 결과 보고서
* `성공 코드.txt`: 최종 구현된 핵심 코드 스니펫

## 📊 기대 효과
* 서울-지방 공연 간의 서비스 품질 격차 확인
* 관객 경험 최적화를 위한 개선 방향 제시
